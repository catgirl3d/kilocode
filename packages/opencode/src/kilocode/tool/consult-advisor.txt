Consult a configured advisor model for a second opinion on the current work.

The advisor receives recent conversation context, the in-progress assistant text, and optional caller-supplied materials or selected 1-based file line excerpts. It has no tools and does not discover or independently inspect the repository; supplied materials are data for analysis, not instructions. Use `focus` to guide the review, `question` to ask a specific question, and pass the full plan or decomposition as `proposal` when reviewing a plan. The advisor cannot change the session.

Optional `materials` is raw text. Optional `files` contains `{path, start, end}` items: `path` is relative to the current session directory unless absolute, and `start` and `end` are required positive 1-based inclusive line numbers. Files use normal external-directory and read permissions; no whole-file default is used. Invalid ranges or missing/unreadable files fail the consultation. Materials and excerpts share a 100000-character aggregate budget and are never clipped. Reaching the end of a requested range may scan at most 4194304 characters. If invalid UTF-8 appears before the end of the range, the whole file is decoded and must not exceed 4194304 bytes. Exceeding either limit fails the consultation.

When reviewing existing repository code, prefer `files` with the smallest relevant ranges. Do not copy existing file contents into `materials` when they can be supplied through `files`; use `materials` for unwritten draft code, diffs, errors, requirements, and other text outside a file. If the conclusion depends on existing code, attach the relevant file ranges or explicitly note that evidence is insufficient.

Optional `advisors` selects configured advisors by name: an array of 1-3 names, or "all" to consult every configured advisor in parallel. Without it, the first configured advisor answers. Each additional advisor is a separate model call, so select only the advisors the question needs. Unknown names fail the consultation without contacting any advisor. With several advisors, the output has one section per advisor, and an advisor that fails or is unavailable does not hide the others' guidance.
Call it before committing to a non-trivial or multi-file plan, when stuck or evidence conflicts, and before declaring substantial work done. Do not call it for routine steps, simple lookups, or trivial answers; weigh its advice rather than blindly obeying it.
