Open the side-question card from a new button next to the chat prompt actions and ask from the card's own question input. While the card shows an answer, both that input and a typed `/btw <question>` ask a follow-up in the same thread; the New question button under the answer, or closing the card, starts a new thread, and a side question waits while another side answer is still starting or running. A refused question comes back to the card input, and the card's own voice-input button is disabled under the same conditions as the main microphone, which hides while the card records.
