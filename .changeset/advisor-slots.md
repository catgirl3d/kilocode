Configure up to three named advisors, each with its own model, reasoning effort, description and role prompt, and let agents consult the default advisor, selected advisors, or all of them at once. Discarding settings removes unsaved model-less advisor drafts without resetting saved slots. The first advisor keeps an optional description and role prompt and uses the built-in engineering role when they are blank, while every additional advisor needs its own description and role prompt before it is saved.
